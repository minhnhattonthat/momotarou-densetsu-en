# Style reference - Momotarou Densetsu

Voice: a comic, all-ages Hudson RPG retelling the Momotaro folk tale, full of puns, pop-culture gags and animals with
verbal tics. English should read like a lively, natural localisation of a 90s Japanese RPG: short punchy sentences,
exclamation marks where the JP has them, no archaic "thee/thou", no modern slang that will date it.

## Voices and tics (use as often as the JP uses its tic, no more)
| Speaker | JP tic | English |
|---|---|---|
| Momotaro | silent hero, never speaks | narration names him: "Momotaro found..." |
| Dog | ワンワン！ | "Woof woof!" |
| Monkey | キャッキャッ！ | "Ook ook!" |
| Pheasant | ケンケン！ | "Kek kek!" |
| Sparrows (inns, shops) | チュチュン！ / チュン | "Chirp chirp!" / "chirp" |
| Mice | チュー！ チュー！ | "Squeak squeak!" |
| Rabbits | ピョン / ピョピョン | "hop!" / "Hop hop!" |
| Cows | モー | "Moo" ("Wanna drink my milk? Moo!") |
| Bombee | ボンビー！ / なのねん | "Bombee!" / ends a line with ", bombee!" |
| Hermits, elders | ～じゃ / ぢゃ / おるぞ | old-man voice: "I am the Escape Hermit! Heh heh!", "Off with you, Momotaro!" |
| Oni, villains | rough / ふふふ | rough or menacing; "Heh heh heh!" for ふふふ |
| Kansai shopkeeper | でっか / へい | folksy: "Hey there, welcome! Whaddya need?" |
| Chinese-accent elevator | アル / ツァイチェン | pidgin kept light: "Welcome-a, yes!" / "Zaijian!" |
