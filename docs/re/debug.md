# Debug tool: RAM map and warp mechanism

Tools: `tools/debug/warp.lua` (driver), `scenes.lua` (scene list), `warp.py` (runner, regen-all),
`fileload.lua` (file-load log probe), `maps.txt` / `files.txt` (map and file tables), `mkmaps.py`.
All addresses are RAM (EXE loaded at 0x80010000). **verified** = warp test with a proof shot in
`work/qa/warp/<scene>/scene.png`, regenerated by `python -X utf8 tools/debug/warp.py --all`.

## Files (verified: fileload.lua log matches what is on screen)
- `cd_load(index a0, dest a1, ?, mode a3)` at 0x8001AC54. Index = MMPS_CD.SFS entry = EXE path table
  0x8006FB94 (`tools/debug/files.txt`). So the game **does** read files through MMPS_CD.SFS (in RAM at 0x8008F710):
  a rebuild that moves or resizes a file must rewrite it (phase 3).
- Boot: SND00/01, HUDTIT (Hudson logo), FONT, EVTTIT (title). New Game: EVTOP (intro).
- SHOP.MMB (file 3) is MIPS code loaded to 0x80155000 by the shop entry functions (0x80020C78, 0x80034EE8 ...).

## Main loop (verified)
- 0x80019128; state s16 at **0x800847E0**, dispatched through the table at 0x80010050 (index state+1):
  -1 quit, 0 load map, 1 battle (0x800192A8), 2 field (0x8001968C -> field loop 0x8002FDE4),
  4 minigame (selector u8 0x800846E8), 5 event (selector u8 0x800847DF), 7 return to map, 8 0x8004F7EC.
- Field loop 0x8002FDE4 runs while u16 **0x800846FA** != 0; set it 0 to drop back to the main loop.
- `goto_map(map, x, y, dir, mode)` 0x8001A4D8 writes {1, map, x, y, dir} to 0x80094A50, map to **0x800847D6**,
  state 0. warp.lua writes the same and clears 0x800846FA (or replaces the New Game intro: state 5 + event 6).
- `load_map(n)` 0x8002D714; map table 0x800729FC (36 B/entry: u16 file index ... u16 room), second table
  0x80077FE4 (16 B: overlay init, EXE init, goto_map callback, s16 parent map). 560 maps: Z00 = overworld
  (map 0), SMAP towns 1-35, HMAP interiors (HMAP00-12 are the per-town shop/inn interiors, room = town),
  DMAP dungeons, NMAP/OMAP/JMAP/WMAP areas. `tools/debug/maps.txt`.
- Last town (respawn) 0x800918FE; script command handlers near 0x80032B20 (start_minigame 0x80032B7C,
  start_event 0x80032B98).

## Battles (verified: random battle on the overworld)
- The field loop sets state 1 when `0x80045670(terrain, ?)` rolls an encounter; 0x8004540C sets up the group.
  Battle loads BBxxx (background) + BMxxx (monster) + FBTL.BIN. A fixed-group warp is not built yet
  (would need an exec hook on 0x8004540C a0, --debugger).
